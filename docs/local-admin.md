# 本地浏览器后台

在项目目录运行 `npm run admin`，打开 <http://127.0.0.1:4320/>。网站预览位于 <http://127.0.0.1:4317/>；如果预览尚未运行，启动器会一并启动 Hexo 本地预览。

Windows 也可以双击桌面「ManaFeng 本地后台」快捷方式，或项目里的 `启动本地后台.vbs`。后台在隐藏窗口中运行，准备完成后自动打开默认浏览器；重复双击会复用已启动的本项目后台。无需每次输入命令，也不需要管理员权限。若端口被其他程序占用，会提示启动失败，详情记录在 `.local-admin/startup.log`。

后台只监听 `127.0.0.1`。所有管理界面、样式和脚本都来自本机，不需要账号或 GitHub 授权。后台没有 Git 提交、远程上传或部署接口；保存不会触发线上发布。需要更新线上网站时，另行手动提交并推送到 GitHub，由 GitHub Actions 检查后发布。

## 文章

- 可以搜索、按分类筛选、创建文章和编辑文章。
- 新文章填写标题、文件短名和分类后创建。短名使用小写英文、数字和连字符，例如 `new-note`。
- 旧文章文件名、日期和永久链接不能通过后台修改，也没有删除文章的操作。
- 正文使用原文编辑，保留现有 HTML、表格和目录锚点。只调整标题、分类、标签或封面时，后台直接保留原有正文的字节。
- 点击「保存到本机」或按 `Ctrl+S` 才保存，没有自动保存。离开有未保存修改的页面时会提示。
- 若文件被其他编辑器或窗口改动，旧窗口的保存会被拒绝。先保留需要的修改，再重新打开文章。
- 保存没有变化的文章不会重写文件。封面可以从本地图片库选择。

## 分类和标签

分类、标签直接来自文章头部信息。后台可以新增候选名称、查看相关文章、批量改名或合并；改名只修改头部信息，不触碰正文和文章地址。

新增但尚未使用的名称保存在本机 `.local-admin/taxonomy.json`，供表单选择。名称在文章使用后才会出现在网站导航。分类和标签自身的导航路径由名称生成，改名时这些导航路径会变化；若以后需要发布并兼容旧导航书签，应先安排跳转。

## 图片

图片库对应 `source/images/`。添加图片只保存到这个本地目录，可复制 `/images/文件名` 路径插入正文。支持 PNG、JPEG、GIF、WebP、AVIF，单张不超过 8 MB。

后台不覆盖同名图片。仍被文章或站点设置引用的图片不能删除；未发现引用的图片可以删除，删除前会备份。

## 备份和停止

旧文章保存、分类批量改名、删除未使用图片前，原文件会复制到 `.local-admin/backups/时间-随机标识/`。如果需要恢复，先停止后台，再把对应备份复制回原目录。

`.local-admin/` 已加入 Git 忽略规则，备份和本地候选分类不会被常规提交包含。后台文件本身位于 `tools/local-admin/`，不会进入 Hexo 生成的网站。

启动终端按 `Ctrl+C` 可以停止后台，以及由它启动的预览。已经单独运行的预览不会被关闭。本地后台启动的预览会跳过本站统计脚本。

通过快捷方式启动时，关闭浏览器不会停止后台；本次 Windows 登录期间可以随时再次双击快捷方式回来，注销或重启电脑会结束后台。快捷方式不会添加开机自启、计划任务或系统服务。

原 Pages CMS 配置已从项目移除，后台不会连接 Pages CMS。相关历史提交保留在 Git 历史中；当前使用本地后台管理内容，只有手动推送才会触发线上更新。
